Area pengelolaan portfolio. Kita sedang menyiapkan autentikasi dan koneksi database agar hanya admin yang berwenang dapat menambah, mengubah, atau menghapus project.

Setup belum selesai. Halaman ini belum menerima login atau menyimpan data. Jangan masukkan password atau data rahasia di sini sebelum Supabase Auth dan Row Level Security selesai dikonfigurasi.

  • 02 Aktifkan Supabase Auth untuk akun admin.
  • 03 Konfigurasikan Storage bucket untuk thumbnail project.
  • 04 Hubungkan dashboard ke database dengan policy RLS.
